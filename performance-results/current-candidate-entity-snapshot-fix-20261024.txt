MultiPaper 26.3 entity snapshot persistence fix — 2026-10-24
===========================================================

Root cause and fix
------------------
Master transient entity writes inflated and merged the previous on-disk entity list into the current `ChunkEntitySlices` snapshot. Entities absent from the current chunk because they had moved out were consequently retained in the old chunk file. `WriteChunkHandler` now validates, UUID-deduplicates, and persists the current transient snapshot as authoritative entity chunk contents. Write acknowledgements still wait for durable RegionFile persistence; malformed snapshots receive a negative reply and release the entity write lock.
