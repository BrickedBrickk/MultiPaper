Command checks
--------------

This exposed a false positive in `scripts/Run-ProxyCommandProbe.js`: it searched for the words “TPS” and “MSPT,” which also appear in the command suggestion for an unknown command. The probe now explicitly rejects `command.unknown.command` and checks the actual TPS/MSPT response headings.
